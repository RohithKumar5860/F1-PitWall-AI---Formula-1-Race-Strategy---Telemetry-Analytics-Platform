# F1 PitWall AI — Application Screenshots & UI Showcase

This directory contains visual references and screenshot placeholders demonstrating the F1 PitWall AI application interface.

## Visual Showcase List

1. **Dashboard Overview** (`dashboard.png`)
   - Displays session telemetry summary, driver standings table, top lap time metrics, and weather conditions.

2. **Advanced Race Analytics** (`race_analytics.png`)
   - Multi-driver lap-by-lap pace progression, inverted Y-axis position trajectory, constructor pace distribution, and sector delta heatmaps.

3. **Tire Performance & Stint Analysis** (`tire_analysis.png`)
   - Compound degradation curves, stint length breakdowns, and tire age pace drop-off statistics.

4. **Pit Stop Strategy & Timeline** (`pit_stops.png`)
   - Pit stop history, stint compound transitions (Sankey flow), and pit lap histogram distribution.

5. **AI Strategy Engine** (`strategy_ai.png`)
   - Interactive decision support tool predicting optimal pit windows, compound recommendations, and urgency assessments.

6. **What-If Race Strategy Simulator** (`simulator.png`)
   - Scenario builder comparing dual pit strategies (Plan A vs Plan B) with stint deltas and total race time projections.

7. **System Diagnostics & Telemetry Inspector** (`diagnostics.png`)
   - Real-time connection latency inspector, FastF1 cache health status, and API status monitoring.
